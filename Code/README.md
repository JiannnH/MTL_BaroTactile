# Firmware

This folder contains the Firmware code for Testing Rig and the Barometric Tactile Sensor.

## Folder Structure

The repository is organized into the following folders:

**Testing_Rig**: Contains the Arduino firmware code for controlling the Testing Rig used in data collection.

**Sensor**: Contains the Arduino firmware code for the Barometric Tactile Sensor, receiving the real-time input for 16 barometers' reading.
